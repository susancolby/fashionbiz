  1. Add or edit products in the Products panel.
    2. 
              
  2. Come back here and click Copy HTML.
    3. 
              
  3. Open products.html in your code editor.
    4.

    5. 
              
  5. Replace the entire contents of .product-grid (all the <article> blocks) with the copied HTML.
    6. 
              
  6. Save the file and push to GitHub.
